GENESIS SPECIFICATION // NWEB-01
NCRYPTD NETWORK

The NWEB Protocol

A Zero-Server, Decentralized Web Standard for UTXO Blockchains.

Credit & Origin

1. Abstract

NWEB is a decentralized web protocol that leverages the physical infrastructure of Proof of Work (PoW) UTXO blockchains to permanently host and serve web pages. By decoupling structural HTML markup (hosted immutably on-chain) from its CSS styling engine (provided natively by the client browser), NWEB transforms global mining networks into a highly efficient Decentralized Physical Infrastructure Network (DePIN) capable of serving a lightning-fast, zero-server internet.

2. Motivation

Traditional web hosting relies on centralized server farms which are vulnerable to censorship, downtime, and domain seizure. Conversely, alternative decentralized storage networks suffer from link rot and require active pinning.

NWEB harnesses the globally distributed computational power of cryptocurrency miners to serve as an immutable web host. When a miner validates a block on a UTXO chain, they are actively participating in a DePIN ecosystem, permanently hosting and securing the NWEB pages inscribed within that block's witness data.

3. Protocol Syntax

For a browser to recognize a raw blockchain inscription as an NWEB Webpage, the text data MUST begin with the NWEB Frontmatter Header. This ensures indexers and browsers can instantly identify, parse, and render the webpage without executing malicious scripts.

--- protocol: nweb version: 1.0 css: tailwind ---

* Immediately following this header, the payload MUST be valid HTML utilizing standard Tailwind CSS utility classes.

4. Proof of Concept & Collaboration

The architecture and rules described in NWEB-01 are submitted purely as a working Proof of Concept (PoC). The goal of this genesis release is to demonstrate that a zero-server UTXO internet is possible and to spark community innovation. Wallet providers (such as Nintondo), indexers, and the broader developer ecosystem are actively invited to take this PoC, optimize the parsing logic, build out the infrastructure, and natively integrate nweb:// routing.
