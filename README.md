## 🌐 What is NWEB?
NWEB is a decentralized web protocol that leverages the physical infrastructure of Proof of Work (PoW) UTXO blockchains to permanently host and serve web pages. 

By decoupling structural HTML markup (hosted immutably on-chain) from its CSS styling engine (provided natively by the client browser), NWEB transforms global mining networks into a highly efficient Decentralized Physical Infrastructure Network (DePIN) capable of serving a lightning-fast, zero-server internet.
